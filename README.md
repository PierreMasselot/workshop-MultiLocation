# Statistical methods for multi-location studies in environmental epidemiology

This repo contains the material for the workshop presented at the *Centre de Recherche Mathématique* on 7th October 2026.

## Lecture slides

Lecture slides are in `workshop-MultiLocation.html`.

The lecture slides have been generated with [quarto](https://quarto.org/) on a [revealjs](https://revealjs.com/) format. If you are curious about the quarto code used to generate the slides, it is in [workshop-MultiLocation.qmd](workshop-MultiLocation.qmd).

## Examples

Both example R scripts are found in the `examples` sub-folder. Necessary data are stored in the `data` sub-folder.

1. [`Stage1_dlnm.R`](examples/Stage1_dlnm.R) illustrates how to use distributed lag nonlinear models to estimate the association between an environmental exposure and a health outcome.

2. [`Stage2_multiLoc.R`](examples/Stage2_multiLoc.R) illustrates how to pool associations from several locations into a meta-analysis model. 

## Other folders

- `files` includes useful files for the slides, including the bibliography data and templates for citations and theming.
- `figures` includes all images necessary to compile the lecture slides.
